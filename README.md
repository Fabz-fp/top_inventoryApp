# Inventory App

An inventory management application build with Node.js, Express, PostgreSQL and EJS as part of The Odin Project.

## Live Demo
Coming soon.

## Features
- Browse product categories.
- View all products within a category.
- View individual product details.
- Create, update and delete categories.
- Create, update and delete products.
- Manage inventory quantities and prices.

## Technologies
- Node.js
- Express
- PostgreSQL
- EJS
- CSS
